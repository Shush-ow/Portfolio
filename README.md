# Next.js ポートフォリオサイト

自主的な学習のアウトプットとして制作した、自身の個人ポートフォリオサイトのリポジトリです。
Next.js、React、Tailwind CSSを用いてフロントエンドを構築し、Vercelを使ってデプロイ・公開しています。

## 🌐 公開URL
https://portfolio-khaki-alpha-57.vercel.app/

---


## 🛠️ 使用スタック（技術構成）

- **フロントエンド**: React / Next.js 
- **スタイリング**: Tailwind CSS
- **ホスティング / インフラ**: Vercel
- **ソースコード管理**: GitHub

---

## 🧠 今後の課題とやってみたいこと

現在は、学校の企業プロジェクトでのAWSインフラ構築経験や、CEH（認定ホワイトハッカー）の自主学習を通じて、「インフラの可用性」や「セキュリティ・信頼性」への興味がめちゃくちゃ強くなっています。

今のこのポートフォリオはVercel任せのシンプルな構成なので、今後は「AWS上に自分でセキュアなインフラを組んで移行する」とか、「脆弱性診断の視点からコードや設定を見直して、より堅牢なシステムにする」といった、インフラ・セキュリティ面でのブラッシュアップにも挑戦してみたいと思っています。
